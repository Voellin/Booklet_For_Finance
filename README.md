# 写给财务看的小册子

写给非技术人的 AI 小册子系列。假设读者是一位财务同事：聪明、忙、没有写过代码。每册一个主题，20 分钟读完，不出现公式。

每册固定带一节「附录/纠偏」——通俗化必然引入失真，失真之处集中标注，绝不藏着。
